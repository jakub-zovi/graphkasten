# Graphkasten
- This second brain implements Graphkasten note taking methodology
	- Learn more at https://graphkasten.com/
- Graphkasten is designed to work with Obsidian and the graph view that it provides
	- To see its beauty open the graph view (left ribbon → *Open graph view*)
	- Toggle Filters -> Tags in the upper right corner on and off
		- This will create nice clusters of notes instead of them being scattered all across the place
		- Explore beautiful graph topology of the notes 😌
