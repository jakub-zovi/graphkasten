# Promptfoo
- [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo)
> Promptfoo is a CLI and library for evaluating and red-teaming LLM applications.
- Github: [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo)
  - 15.8k stars
  - MIT license
## Features
- Declarative YAML config for prompt testing
- Assertion types: string matching → LLM-as-judge rubrics
- Red-teaming / security vulnerability scanning
- Model comparison across providers (OpenAI, Anthropic, Gemini, Llama, etc.)
- CI/CD integration for automated checks
