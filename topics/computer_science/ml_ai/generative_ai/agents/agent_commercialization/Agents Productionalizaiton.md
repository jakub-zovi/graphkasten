# Commercialization of Agents
While it is easy to create impressive POC with agentic approach, the productionalization and commercialization of the agents is much more difficult. There are many ways people try to commercialize agents from building Agent Marketplaces to creating dedicated [[Agent Companies]] that try to build highly specialized vertical agents.
