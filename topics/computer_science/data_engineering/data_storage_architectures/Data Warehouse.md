# Data Warehouse
Subject-oriented, integrated, time-varying, non-volatile collection of data use for organizational decision making.
- subject-oriented - data related to same real-world event are linked together
- integrated - contains all the organization data that is made consistent
- non-volatile - data is static, read-only and retained for future reporting
- time-varying - data is tracked and recorded so that reports show changes over time
Data warehouse consists of [[Data Mart]]s which is subset of data for specific business department.
## Pros:
- **Business intelligence (BI)**
- **Analytics**
- **Structured & clean data**
- **Predefined schemas**
## Cons:
- **No support for semi or unstructured data**
- **Inflexible schemas**
- **Struggled with volume and velocity upticks**
- **Long processing time**
