# Graph
[^1]ChatGPT:
> The **graph data model** represents data as a network of interconnected nodes and edges. It is ideal for modeling complex relationships and associations. The two primary components are:
> 
> - **Nodes**: Represent entities or objects (e.g., people, products, locations).
> - **Edges**: Represent relationships or connections between nodes (e.g., "FRIEND_OF," "PURCHASED").
> - **Properties**: Attributes attached to nodes or edges to store additional data (e.g., name, age, date).
> 
> This model allows for intuitive representation of data like social networks, recommendation systems, and supply chains.
