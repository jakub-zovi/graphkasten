# Ghostty
- [Ghostty](https://ghostty.org/):
> a fast, feature-rich, and cross-platform terminal emulator that uses platform-native UI and GPU acceleration.
- Created by Mitchell Hashimoto (founder of HashiCorp), written in Zig
## Key Features
- **GPU acceleration**
	- Renders via GPU for high performance on large outputs and smooth scrolling
- **Native platform UI**
	- Uses native widgets on macOS and Linux instead of a custom toolkit
- **Cross-platform**
	- Runs on macOS and Linux (Windows support planned)
- **Zero-configuration**
	- Works out of the box with sensible defaults, no setup needed
- **Highly configurable**
	- Hundreds of configuration options for appearance and behavior
- **Theming**
	- Hundreds of built-in color themes, with separate light/dark mode themes
- **Custom keybindings**
	- Flexible keybind configuration for personalized shortcuts
- **Terminal API**
	- Comprehensive support for terminal control sequences and modern features
