# Secure ShellFish
- Native SSH terminal + SFTP client for iOS, iPadOS, and Mac. Best known for surfacing remote directories through the system Files.app / Finder.
## Highlights
- Files.app / Finder integration — remote server dirs appear as native locations, apps can open files in-place.
- Terminal output scans for filenames — preview, drag, share as real files.
- Multi-touch mapping (cursor drag = arrows, tap = mouse click).
- Security keys, short-lived SSH certificates, Secure Enclave key storage.
- iCloud Keychain sync of host configs; iCloud sync for snippets.
- Widgets, Live Activity, Picture-in-Picture for long-running tasks.
## Pricing
- Free to try. One-time pro purchase covers all devices; monthly subscription also available.
