# Blink Shell
- Open-source, Mosh-first terminal for iPhone and iPad. Long-standing pro tool that predates the AI-agent wave; still one of the sharpest raw terminals on iOS.
- Built on libssh / libssh2, ships Unix tools (vim, curl, tar, dig) inside the app.
## Highlights
- Mosh protocol with intelligent local echo — no lag, sessions survive sleep and network change.
- SSH: Ed25519, ECDSA, RSA, `-L` tunnels, ProxyCommand, ssh-agent, PKI auth.
- SFTP + Files.app integration.
- Blink Code: remote VS Code, GitHub Codespaces, GitPod integration.
- Vim/Emacs-tier keyboard customization, external display up to 4K, Apple TV.
- Cross-device sync of settings and hosts.
