# Termius
- Cross-platform SSH client aimed at productivity and team collaboration. Not an agent tool — general infra remote-access product used by ~2M engineers.
## Platforms
- macOS, Windows, Linux, iOS, Android.
## Highlights
- SSH terminal + SFTP file transfer.
- Encrypted vault with cross-device sync of hosts, keys, snippets.
- Host grouping, port forwarding, serial connection, command snippets, session logs.
- Team vaults, shared credentials, admin controls for org accounts.
## Pricing
- Freemium. Paid tiers unlock sync, SFTP, team features (see [termius.com/pricing](https://termius.com/pricing)).
