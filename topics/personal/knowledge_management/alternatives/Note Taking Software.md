# Note Taking Software
- This note aggregates information about different note taking softwares and my opinions about them
## Note Taking Apps
- [[Obsidian]]
	- So far the best note taking software out there
- [[OneNote]]
	- I have used OneNote extensively for taking notes during my masters studies
- [[VS Code with Markdown]]
	- I have used this experimentally before fully committing to Obsidian
- [[CherryTree]]
	- A hierarchical note taking application, featuring rich text and syntax highlighting, storing data in either a single file (xml or sqlite) or multiple files and directories
	- This was note taking software that I used during my bachelor's studies when I had Linux as my main operating system
	- I have some old backups in the cloud
- [[Logseq]]
	- A Obsidian contender that I do not see any reason to switch to
