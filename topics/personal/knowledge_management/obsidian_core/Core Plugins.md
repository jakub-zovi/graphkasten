# Core Plugins
- Core plugins are officially built and supported by the Obsidian team, and are included within the application.
## List
- [[Graph View]] ([Link](https://help.obsidian.md/plugins/graph))
	- Visual map of all notes and their connections
- [[Obsidian Bases]]
	- Database-style views with queries over vault notes
- [[Canvas]]
	- Infinite visual whiteboard for embedding notes, media, and cards
- [[Backlinks]]
	- Shows all notes linking to the current note; includes unlinked mentions
- File Explorer
	- Browse and manage vault files and folders in the sidebar
- Search
	- Full-text search across all vault notes
- Quick Switcher
	- Fast keyboard-driven navigation to any file by name
- Outgoing Links
	- Lists all links originating from the current note, plus unresolved links
- Tags
	- Browse and filter notes by tag in a dedicated sidebar pane
- Properties
	- Edit and view YAML frontmatter as a structured form
- Daily Notes
	- Create or navigate to today's journal note with a single command
- Templates
	- Insert reusable text snippets into the current note
- Note Composer
	- Merge two notes or split a note at the cursor
- Command Palette
	- Access any Obsidian command by name via keyboard shortcut
- Editor Status
	- Displays word and character count in the status bar
- Bookmarks
	- Save and organize frequently accessed notes and searches
- Outline
	- Navigate headings within the current note from a sidebar panel
- Word Count
	- Shows word and character count for the current note
- Slides
	- Present a note as a slideshow using `---` as slide separators
- Audio Recorder
	- Record audio and embed it directly into a note
- Workspaces
	- Save and restore panel layouts and open-file sets
- File Recovery
	- Access recent automatic snapshots to recover lost content
- Footnotes
	- Add and manage footnotes with automatic numbering
