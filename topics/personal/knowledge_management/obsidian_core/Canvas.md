# Canvas
- Canvas is a core plugin that provides an infinite whiteboard for visual thinking, brainstorming, and organizing ideas spatially.
- Canvas files use the `.canvas` extension and are stored as JSON.
## Key Features
- **Cards** — standalone text cards without a corresponding note file
- **Embedded notes** — drag any vault note onto the canvas; edits sync back to the note
- **Media** — embed images, PDFs, and web pages directly on the board
- **Connections** — draw labeled arrows between any nodes to express relationships
- **Groups** — surround nodes with a colored group frame for visual clustering
## Usage in This Vault
- Useful for mapping relationships between concepts before writing a cluster of notes
- Can replace a rough mind-map sketch before committing to a formal note hierarchy
