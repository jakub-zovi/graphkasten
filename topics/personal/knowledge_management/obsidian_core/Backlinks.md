# Backlinks
- The Backlinks core plugin shows all notes that link to the currently open note, making it easy to navigate the graph in reverse.
## Panels
- **Backlinks pane** — sidebar panel listing every note that contains a `[[wikilink]]` or `[markdown link]` pointing at the current file
- **Linked mentions** — explicit links found in other notes
- **Unlinked mentions** — plain-text occurrences of the note title that are not yet linked; useful for discovering implicit connections and converting them to real links
## Outgoing Links
- A companion panel (Outgoing Links core plugin, enabled alongside Backlinks) shows all links originating from the current note, plus unresolved links that have no target file yet
## Relevance to This Vault
- Critical for a graph-centric approach: backlinks let you discover unexpected connections and keep the [[Graph View]] dense and meaningful
- Regularly checking unlinked mentions is a low-effort way to strengthen the link graph without rewriting notes
