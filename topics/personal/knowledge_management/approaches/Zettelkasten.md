# Zettelkasten
- A knowledge management method developed by German sociologist **[[Niklas Luhmann]]**, who used it to produce 50 books and over 600 articles. The word literally means "note box" in German.
- [Introduction to the Zettelkasten Method](https://zettelkasten.de/introduction/):
> A Zettelkasten is a personal tool for thinking and writing. It emphasizes connection, not collection.

## Core Principles
1. **Hypertextual** — notes link to one another, creating a web of ideas
2. **Atomic** — each note contains exactly one discrete idea
3. **Personal** — one person maintains one Zettelkasten

## Note Types
- **[[Fleeting Notes]]** — quick, temporary captures of in-the-moment ideas; meant to be refined later
- **[[Literature Notes]]** — key points from books, articles, or other sources; written in your own words
- **[[Permanent Notes]]** — long-term notes synthesized from fleeting/literature notes; standalone and self-explanatory

## Anatomy of a Note (Zettel)
Each note has three components:
- **Unique identifier** — time-based, hierarchical, or arbitrary
- **Body** — original thought written in your own words (not copied quotes)
- **References** — source citations or links to related notes

## Workflow
1. Capture ideas as fleeting notes
2. Process sources into literature notes
3. Synthesize into permanent notes with explicit link context
4. Use **Structure Notes** as organizational hubs / entry points (similar to MOC files)

The key differentiator is the **link context** — always annotate *why* a connection exists between notes, not just that it exists.

## Critiques
- [[Why I Ditched Zettelkasten]] ([Link](https://www.evchapman.com/blog/why-i-ditched-zettelkasten-for-a-centuries-old-note-taking-system-you-should-too))
	- Ev Chapman argues Zettelkasten is an academic-research system built for pre-search-era workflows, and proposes the commonplace book as a lighter alternative for non-researchers
