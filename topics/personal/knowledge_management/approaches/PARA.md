# PARA
- A universal organizational system created by **Tiago Forte**, introduced as part of his Building a Second Brain  framework. 
- PARA organizes all information by **actionability** rather than by topic or subject.
- [[The PARA Method The Simple System for Organizing Your Digital Life in Seconds|The PARA Method]]
> Your system has to give you time, not take time.

## The Four Categories
| Letter | Category         | Description                                                                                   |
| ------ | ---------------- | --------------------------------------------------------------------------------------------- |
| **P**  | **[[Projects]]** | Short-term efforts with a specific goal and deadline (e.g., write a report, launch a feature) |
| **A**  | **[[Areas]]**        | Ongoing responsibilities with standards to maintain (e.g., health, finances, marketing)       |
| **R**  | **[[Resources]]**    | Topics of ongoing interest for future reference (e.g., graphic design, productivity)          |
| **A**  | **[[Archives]]**     | Inactive items from the other three categories, preserved for future reference                |

## Key Principles
- **Actionability over subject** — organize by what you're doing with information, not what it's about
- **Projects vs. Areas distinction** — projects have a finish line; areas are indefinite responsibilities
- **Simplicity** — the system should reduce friction, not create it

## Benefits
1. **Clarity on commitments** — breaking areas into specific projects reveals actual workload
2. **Psychological momentum** — completing projects creates regular, measurable victories

## Relation to CODE Framework
PARA is the organizational backbone of Forte's broader **CODE** process:
- **C**apture → **O**rganize (PARA) → **D**istill → **E**xpress
