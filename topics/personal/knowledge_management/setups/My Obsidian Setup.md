# My Obsidian Setup
- Aspects features of my knowledge management system:
	- [Maps of Content](https://obsidian.rocks/maps-of-content-effortless-organization-for-notes/) (MOC)
		- Main tool for structuring notes without relying on folders or tags
	- Graph centric approach ([[Graphkasten]])
		- **Graph view is main navigation tool** and not just nice to have features
			- Everything is displayed and navigated using Graph View
			- There are some exception tough, following things are 
		- Need to maintain the graph (tag coloring, tag managements, filters etc.)
	- Use of Local Graph View to see the context of a note
	    - **Context is very important in my system. It gives the information (note) its value!**
	- Use of front matter in each node to specify tags, created and modified date, sources and topics
	- Backups done through GIT not only for notes, but also for whole vault and Obsidian configuration (plugins, styles etc.)
	- [Digital Garden](https://maggieappleton.com/garden-history/#the-six-patterns-of-gardening) approach instead of PARA or Zettelkasten
