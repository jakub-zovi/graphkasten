# Community Plugins
- Use plugins to adapt Obsidian to fit your specific needs, such as support for additional file formats or integrating with a third-party service
- Community plugins run third-party code on your behalf that could potentially do harm
## List
- [[Templater]]
	- Full scripting template engine with dynamic dates, prompts, and folder-triggered auto-insertion
- [[Obsidian Git Plugin]]
	- Git backup workflow; manual commits, push disabled, split-diff view
- [[Spaced Repetition Plugin]]
	- SM-2 spaced repetition flashcards and note review directly in the vault
- [[Excalidraw Plugin]]
	- Embedded whiteboard drawings stored as `.excalidraw.md` files
- [[Extended Graph Plugin]]
	- Beta plugin for link-type filtering and advanced graph coloring
- [[Obsidian Digital Garden]]
	- Free and open-source publishing tool for sharing vault notes publicly
- [[Banner Images + Icons (Experimental)]]
	- CSS snippet integration for banner images and icons on notes
- [[Folder Bridge Plugin]]
	- Enables mounting folders from file system and cloud into Obsidian
		- Hence these folders can be used as if they were inside the vault
	- Also enables hidden folders and files in the file navigation bar
	- [Obsidian_FolderBridge](https://github.com/tescolopio/Obsidian_FolderBridge)
		- Currently needs to be installed via BRAT
	- [Stop Copying Files Into Obsidian | Folder Bridge Plugin](https://www.youtube.com/watch?v=dFrBCvSy360)
- [[Task-Board Plugin]]
	- Kanban board with swimlane support — first Obsidian kanban to offer it
- [[Book Search Plugins]]
	- Generate book notes from Google Books / Goodreads / Open Library / Calibre via template
- Calendar
	- Sidebar calendar view linked to daily notes
- Convert URL to IFrame
	- Convert a URL in the editor to an embedded iframe
- Frontmatter Markdown Links
	- Render markdown links inside frontmatter fields as clickable links
- Frontmatter Modified Date
	- Auto-updates the `modified` frontmatter field on every save
- Highlightr
	- Multi-color text highlighting with a floating toolbar
- Editor Shortcuts
	- Adds common editor shortcuts (select word, line, etc.) missing from default Obsidian
- Footnote Shortcut
	- Keyboard shortcut to insert and navigate footnotes quickly
- Icon Folder
	- Assign emoji or Lucide icons to folders and files in the file explorer
- Style Settings
	- UI for configuring CSS variables exposed by themes and snippets (used with Prism theme)
- Tag Folder
	- Visualize and navigate tags in a folder-like sidebar tree
- BRAT
	- Install and auto-update beta plugins from GitHub before official release
- Advanced Tables (Table Editor)
	- Spreadsheet-style editing for markdown tables with auto-formatting
- Terminal
	- Embedded terminal (shell) panel inside Obsidian
- URL into Selection
	- Paste a URL over selected text to create a markdown link automatically
