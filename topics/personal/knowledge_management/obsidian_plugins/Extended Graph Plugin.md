# Extended Graph Plugin
- Community plugin by ElsaTam (beta) that extends Obsidian's built-in [[Graph View]] with advanced filtering and link-type awareness.
## Key Capabilities
- **Link-type filtering** — filter graph edges by the type of relationship (e.g. show only `[[links]]` of a certain semantic kind), solving the lack of native link-type support described in [[Obsidian Link Types]]
- **Node coloring** — color nodes by tag, folder, or custom property beyond what the built-in graph offers
- **Interactive legend** — toggle visibility of node/link groups from a sidebar legend
## Status
- Currently in beta; installed via BRAT (Beta Reviewers Auto-update Tool) for early access
- API may change between versions — monitor the GitHub repo for breaking changes
## Why Watching It
- Native Obsidian has no concept of typed links (see [[Obsidian Link Types]]); this plugin is the most promising current solution for link-type filtering in the graph
